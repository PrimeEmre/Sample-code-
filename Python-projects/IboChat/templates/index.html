What is IboChat?

IboChat is a free AI voice chat app: pick a character, talk out loud, and hear a realistic voice answer in 24+ languages. Character voices are cloned with GPT-SoVITS, speech input runs on Whisper, and the conversation is powered by the GLM large language model — all served from a single Flask app.

Curious how it works? Read How I Built IboChat: An AI Voice Chat App with Custom Characters, or browse the Emre Guzel Coding Blog for more on building AI agents in Python. All characters are AI-generated parodies, not affiliated with any real person.
